About Lecture4All

Lecture4All is an intelligent educational video retrieval platform providing universal cross-lingual semantic search across academic lectures in any language.

Universal Any-to-Any Cross-Lingual Architecture

Lectures can be delivered and recorded in any supported language — English, Dutch (Nederlands), Tamil (தமிழ்), Malayalam (മലയാളം), or Hindi (हिन्दी). Spoken audio is transcribed with word-level timestamps using Whisper. Both the transcripts and student search queries are mapped into a shared 512-dimensional multilingual vector space using the Universal Sentence Encoder. This allows students to search naturally in any language and instantly retrieve relevant lecture segments regardless of the video's original spoken tongue.
